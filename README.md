# 校园网开机自动登录（Windows）

开机登录 Windows 后，脚本会自己完成校园网认证，不用再打开浏览器点登录。

主脚本 `CampusNet-AutoConnect.ps1` 直接调用学校认证网关的登录接口
（`http://172.168.254.4:801/eportal/?c=ACSetting&a=Login`），不需要解析网页，所以不受登录页改版影响。

> 说明：脚本文件名和脚本内容都是纯英文（这样在任何系统语言、任何编码下都不会乱码）；
> 只有这份说明书是中文。

---

## 一、一次性设置

1. **把这个文件夹放到一个固定位置**，例如 `D:\CampusNet\campus-net-autologin`。
   以后不要随便挪动；如果挪了，重新做一次第 4 步即可。

2. **确认账号密码**：用记事本打开 `CampusNet-AutoConnect.ps1`，前几行就是配置：

   ```powershell
   $script:Username = 'YOUR_STUDENT_ID'  # 改成你的学号
   $script:Password = 'YOUR_PASSWORD'    # 改成你的密码
   $script:Service  = 'Free'             # 套餐（脚本里目前没用到，留着即可）
   $script:PortalUrl = 'http://172.168.254.4/a79.htm'
   ```

   > 从 GitHub 下载的版本里，账号密码是占位符，**必须自己填**才能用；
   > 你本机上已经填好的那份不受影响。

3. **测试**：双击 `2-Test-Now.cmd`。窗口里会显示过程，最后：
   - `[OK] Campus network is connected.` → 成功，可以进第 4 步；
   - `[FAILED]` → 看同目录 `logs\CampusNet-AutoConnect.log` 的最后几行。

4. **安装开机自启**：双击 `1-Install-AutoStart.cmd`。
   它往 Windows 的"启动"文件夹放一个小启动器，开机登录后在后台**静默常驻运行**：
   - 开机时立刻检查一次，能上就直接待命，上不了就自动登录；
   - 之后每 30 秒检查一次，**断网自动重连**；
   - **电脑休眠 / 睡眠唤醒后**，网卡重连上最多 30 秒内就会自动重新认证，不用你点任何东西；
   - 全程不弹窗口、不需要管理员权限。
   想取消就双击 `3-Uninstall-AutoStart.cmd`。

## 三、它的工作方式

1. 先检测外网是否通（微软 / Google 的连通性检测地址）。**已经能上网就直接退出**，不会发多余的登录请求。
2. 上不了网时，读取设备当前 IP，再向认证网关的登录接口提交账号密码。
   先试 `,0,学号` 这种格式，不行再试纯学号——不同学校要求不一样。
3. 每次提交后等 3 秒再检测外网；最多重试 5 次，每次间隔 5 秒。
4. 通了就返回成功（退出码 0），全失败返回 `[FAILED]`（退出码 1）。

开机自启用的是**监控模式**（脚本自带的 `-Watch`）：登录成功后不退出，
每 30 秒检查一次，发现断线（包括睡眠唤醒后网卡重新连上）就再认证一次。

日志里关键的两行：

```
[INFO] Internet is fully functional.     ← 已经在线，无需登录
[INFO] Campus Network online.             ← 登录成功
```

## 四、开机自启的两种模式

**默认（推荐）：常驻监控** —— 双击 `1-Install-AutoStart.cmd` 就是这种。
后台常驻，断线 / 睡眠唤醒后 30 秒内自动重连，看门狗还保证不会同时跑两份（不会重复登录）。

**只登录一次**：如果不想让它在后台长期运行，在文件夹里用 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\AutoConnect-Setup.ps1 -NoWatch
```

这样每次开机登录只跑一次就退出。想改回监控模式，重新双击 `1-Install-AutoStart.cmd`。

想彻底关掉开机自启：双击 `3-Uninstall-AutoStart.cmd`（已经在内存里的看门狗会在下次注销/重启后消失，它本身没有任何副作用）。

## 五、常见问题

**开机后要过十几秒才连上，正常吗？**
正常。开机时网卡、DHCP、网关都还没就绪，脚本本身会重试 5 次；就算这 5 次都赶上网络没起来，
常驻监控也会在 30 秒后再试，不用管它。

**合盖睡眠 / 休眠唤醒之后会自动重连吗？**
会。唤醒后电脑的网卡重新连上网，看门狗最多 30 秒内就会检测到"上不了网"并重新认证一次。
如果你着急用，也可以双击一次 `2-Test-Now.cmd` 手动催它一下。

**会不会同时跑好几份、互相打架？**
不会。看门狗用系统级互斥锁保证只有一份在跑；主脚本每次登录前也先检测是否已经能上网。

**会不会重复登录、把账号顶下线？**
不会。每次运行前先检测是否已经能上网，在线的话一个登录请求都不发。

**密码是明文放在文件里，安全吗？**
脚本只在你本机运行，不会上传。介意的话，把整个文件夹的访问权限收到只有你自己能看。

**换宿舍 / 换 IP 之后还能用吗？**
能。脚本用的是本机当前 IP，AC 的 IP 取不到时会用 `172.168.254.100` 这个默认值。

**学校登录接口变了怎么办？**
把 `logs\CampusNet-AutoConnect.log` 的最后几行发给我，或者双击 `0-Collect-Logs.cmd` 收集日志，我来改。
